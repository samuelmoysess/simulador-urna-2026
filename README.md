# 🗳️ Urna Digital 2026 | Simulação

Uma simulação interativa de uma urna eletrônica, desenvolvida com **HTML, CSS e JavaScript**, com interface inspirada no sistema de votação brasileiro.

O projeto permite simular votos em candidatos fictícios ou públicos, visualizar os dados na tela e acompanhar os resultados de uma eleição simulada.

> ⚠️ **Aviso:** Este projeto é exclusivamente educacional e demonstrativo. Não possui vínculo oficial com o Tribunal Superior Eleitoral (TSE) e não representa uma urna eletrônica oficial.

---

## 📌 Sobre o projeto

A **Urna Digital 2026** foi criada para demonstrar, de maneira interativa, como pode funcionar uma interface de votação eletrônica.

O sistema apresenta um teclado numérico, identificação de candidatos, confirmação de votos e uma área de resultados com a quantidade de votos e os respectivos percentuais.

O projeto também inclui efeitos sonoros eletrônicos para tornar a experiência mais interativa.

## ✨ Funcionalidades

- 🗳️ Interface inspirada em uma urna eletrônica.
- 🔢 Teclado numérico interativo.
- 👤 Identificação de candidatos pelo número digitado.
- ✅ Confirmação de votos.
- ⚪ Opção de voto em branco.
- ❌ Correção da votação antes da confirmação.
- 📊 Apuração simulada com quantidade e percentual de votos.
- 🔊 Efeitos sonoros gerados pelo navegador.
- ⌨️ Suporte ao teclado físico do computador.
- 📱 Layout responsivo para diferentes tamanhos de tela.
- 🔄 Opção para reiniciar a simulação.

## 🚀 Como executar

Você pode executar o projeto localmente seguindo estes passos:

1. Clone este repositório ou baixe os arquivos.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador atualizado.
5. Comece a simulação digitando o número de um candidato.

Não é necessário instalar dependências ou configurar um servidor para executar a versão básica.

## 🎮 Como utilizar

1. Digite o número de um candidato no teclado da urna.
2. Confira as informações exibidas na tela.
3. Clique em **CONFIRMA** para registrar o voto.
4. Utilize **CORRIGE** para limpar o número digitado antes da confirmação.
5. Utilize **BRANCO** para selecionar um voto em branco e confirme a escolha.
6. Acompanhe os resultados da simulação.

Também é possível utilizar o teclado físico do computador para digitar os números, pressionar `Enter` para confirmar e utilizar `Backspace` ou `Escape` para corrigir.

## 📊 Resultados

A aplicação apresenta uma apuração demonstrativa com:

- Quantidade de votos registrados.
- Percentual de votos de cada opção.
- Total de votos contabilizados.
- Barras visuais para facilitar a comparação dos resultados.

Os dados são mantidos durante a execução da página e podem ser zerados ao reiniciar a simulação.
